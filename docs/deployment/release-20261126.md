## Database mã hóa

Gói public:`deployment/database/hotelops-20261126.bak.enc` (gzip + AES256GCM).
Khóa riêng:`deployment/private/hotelops-20261126.key` trên máy tạo gói, được gitignore; chuyển khóa tới server qua kênh riêng. Không tải khóa lên GitHub.

Backup COPY_ONLY/CHECKSUM và RESTORE VERIFYONLY WITH CHECKSUM đã đạt. Giải mã được kiểm tra bằng SHA256 trùng từng byte với backup gốc.

- SHA256 gói:`a30b96de57285dd523b4be6e55324f8df5f4955d8a8f909d36db8066d93d04b9`.
- SHA256 backup:`5b2d0e071afc6c6c864f2e1548516a33086d78d7933c9f7c4addb332b143402d`.

```bash
node deployment/database-package.mjs decrypt \
  deployment/database/hotelops-20261126.bak.enc \
  /opt/hotelops/shared/hotelops-20261126.bak \
  /opt/hotelops/shared/hotelops-20261126.key
bash deployment/init-database.sh --restore /opt/hotelops/shared/hotelops-20261126.bak
```

Script init từ chối DB đã tồn tại và ánh xạ logical files sang đường dẫn Linux. Chưa chạy restore gói mới trên Linux trong lượt push này. Không chạy lại cleanup/nhập kho lịch sử trên backup đã cập nhật.

DB đang tồn tại cần backup trước, dừng API/worker, áp dụng riêng `scripts/database/compact-v2/note-25-11-refill-om.sql` và kiểm tra trước khi bật release mới. Không dùng init hoặc restore đè để nâng cấp DB hiện có.

## Cấu hình

Cấu hình máy, ConnectionStrings:HotelOpsDb, SMTP/AI credentials, khóa DataProtection và file `.env` thực tế không được commit. Cấp secrets trên môi trường đích theo [hướng dẫn AWS](aws-docker.md).
