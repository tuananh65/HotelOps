# A. Feature Inventory

Đếm rõ phạm vi: **3 nghiệp vụ Backend public** có logic thật (Login, Logout, Change Password), **4 endpoint hỗ trợ/template**; tổng **7 controller action routes**. Có thêm service provision/reset nội bộ, chưa phải UC quản trị hoàn chỉnh. **4 khả năng FE–BE đã chạy**: Login, Logout, Change Password, Profile/restore-session. Forgot Password là UI local đúng mô hình SRS, không cần reset-email API.

| Chức năng | Endpoint/service | UC | Trạng thái | Bằng chứng/giới hạn |
| --- | --- | --- | --- | --- |
| Login | POST /api/auth/login | UC-001 | PARTIALLY IMPLEMENTED | SQL credentials, lockout, sessions có; không tính effective grants |
| Logout | POST /api/auth/logout | UC-002 | IMPLEMENTED | SQL revoke chạy; expired/revoked CSRF exception lỗi, audit actor thiếu |
| Change Password | POST /api/auth/change-password | UC-003 | IMPLEMENTED | SQL hash, revoke-all, rotate session có; UI messages/field errors sai |
| Current Session | GET /api/auth/session | Hỗ trợ UC-001/002/003 | IMPLEMENTED | SQL validate/touch, user DTO; thiếu role/scope/email |
| CSRF Bootstrap | GET /api/auth/csrf | Technical support | IMPLEMENTED | Secure token + cookie; binding thay đổi khi session invalid gây lỗi logout |
| Database Health | GET /api/health/database | Technical support | IMPLEMENTED | SQL SELECT 1 thực, không trả bảng nghiệp vụ |
| WeatherForecast | GET /WeatherForecast | Không thuộc SRS | IMPLEMENTED | Template random, không đọc SQL và không phải nghiệp vụ HotelOps |
| Temporary provision/reset service | Không có HTTP endpoint | Một phần UC-004/005 | PARTIALLY IMPLEMENTED | Prepare/Apply, one-time delivery, expiry 24h, revoke/audit; đã test trực tiếp service |
| Session revoke-all/hash/lockout helpers | Không phải API độc lập | Hỗ trợ UC-001..003 | IMPLEMENTED | Được gọi bởi auth workflow; không tính thành UC public mới |
| Create/update/activate users; assign roles/scope | Không có endpoint | UC-004..010, UC-141 | NOT IMPLEMENTED | Entity/DTO/frontend không đủ chứng minh triển khai |
| Access review/permission policies | Không có endpoint; AddAuthorization không có RBAC policies | UC-011 | NOT IMPLEMENTED | Session không trả grants; actor/scope chưa được tính |
| Prototype mock files | src/mocks/* | N/A | MOCK ONLY | Các helper dữ liệu mock tồn tại, không import vào runtime live; không dùng thay SQL trong test |
